# Institutional Strategy Audit — 2026-08-31

Purpose: independently audit the prior ChatGPT research on institutional cycle frameworks, entry/exit logic, real investable-product performance, and position transparency.

## Headline conclusion

The evidence supports a narrower conclusion than the earlier chat wording:

1. **Trend-following (AQR / Man AHL) has the strongest directly investable evidence for a distinct systematic return source**, but realized Sharpe is modest and returns are episodic.
2. **State Street MRI is better interpreted as a risk-regime / position-sizing input than as a standalone directional alpha signal.** State Street's own rebalancing research shows similar long-run return with somewhat lower drawdown, not a clear return boost.
3. **Fidelity / JPMorgan / BlackRock / PIMCO multi-asset products do not demonstrate a robust, persistent macro-timing alpha over simple benchmarks.** Some windows outperform, others underperform.
4. **GMO valuation is plausibly useful for long-horizon expected returns, not short-horizon entry/exit timing.** Product results should be read with gross/net and one-off-event caveats.
5. **Bridgewater All Weather is portfolio architecture, not a market-timing signal.** The public ALLW ETF is too new to support long-run conclusions.
6. **House views are not fund returns.** A BlackRock BII overweight, Fidelity business-cycle regime, or JPM asset-class view cannot be validated by attaching the return of an arbitrary same-firm fund.
7. **13F is not the true portfolio.** Shorts, many derivatives, futures, swaps, FX, and non-13F assets are missing.

## Recommended model use

- Macro / earnings regime: prior/context, not direct trade trigger.
- Valuation: long-horizon expected-return layer.
- Trend: confirmation layer.
- Credit / liquidity / volatility regime: position-sizing and risk layer.
- Vanguard-style static allocation / rebalancing: control group.

## Audit status

This repository intentionally distinguishes:

- `VERIFIED`: supported by a primary or official source.
- `PARTIAL`: product evidence exists but does not prove the broader institutional framework.
- `UNVERIFIED`: prior-chat claim could not be independently confirmed in this pass.
- `CORRECTED`: prior-chat wording/number was too strong, mismatched, or insufficiently sourced.
