# 项目现状（Source of Truth）

更新：2026-08-28，Asia/Kuala_Lumpur

## 一句话结论

本地资料尚不能建立 2009 年以来真正的、成分加权且时点正确的 QQQ EPS 序列；旧工作只证明了 2023-12-31 的 3 条持仓候选可以被一个窄验证器识别，不能证明 EPS 因子有效。

## 最终目标

研究以下资料能否预测未来 Nasdaq-100 / QQQ 指数收益：

- 指数成分股盈利增长或盈利修正
- Fed funds 方向或斜率
- 通胀
- 失业
- 商品价格增长
- 指数成分与权重变化

最终必须经过简单基线、滚动样本外验证（walk-forward OOS）、交易成本和稳定性检查。

## 已经证明（Verified）

1. 本地有 38 个 QQQ 持仓快照：2008-2018 基本只有年度快照，2019Q3 以后才有季度 N-PORT。
2. 本地没有完整的公司级历史 EPS 预测/分析师修正 vintage，因此无法从现有本地资料重建真正的 QQQ forward-EPS revision。
3. 官方 Nasdaq 同口径答案的有界搜索只确认 6 个，冻结要求是 8 个；结果为 BLOCK，不得用其他口径凑数。
4. 已冻结的 candidate-3 验证器在普通 Python 与 `python -O` 下都通过：每种模式 90 个 fixture、7 个 unit、8 个 global，共 105 项，另含 5 份真实 SEC 文件和 3 条 N-PORT 行。
5. 5 份证书映射为 3 条唯一行：AAPL、AMZN、NVDA；重复证书不会重复计算权重。三行权重合计 `0.17821800823463242221404735382`。
6. 所有验证包均保持 `promotions_written=0`；Phase 0、生产数据、EPS、预测和回测都没有因此被修改或运行。
