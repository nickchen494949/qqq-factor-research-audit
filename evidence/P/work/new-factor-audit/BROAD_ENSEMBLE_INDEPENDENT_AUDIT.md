# 全历史弱信号代表组合｜独立只读审计

## 结论：审计通过，但研究正式结论只能是 `BLOCK_SAMPLE`

人话：代码和数字没有算错；真正卡住的是合法样本只有 **39季**，低于事前写死的40季。并且即使把39季当诊断看，12条组合仍输给最好单条 VIX，完整年份也只赢一半，所以没有理由用复杂模型救场。

## 合同与日期

- 冻结合同 SHA-256：`feeab5db5be07dd7b66de64db4daf6bea3fe9bfc22565703afabb05664de57ea`，独立重算匹配。
- 69个真实季度中，old8共同完整样本为 **65季**：2009Q1缺少部分旧系列；另有3个假日周五标签晚于真实季末，按合同必须删除。
- `2013Q1`：旧标签 `2013-03-29`，真实季末 `2013-03-28`。
- `2018Q1`：旧标签 `2018-03-30`，真实季末 `2018-03-29`。
- `2024Q1`：旧标签 `2024-03-29`，真实季末 `2024-03-28`。
- 每个日期问题同时影响8条 old8，共24个无效旧记录；没有重复季度。
- 合法旧信号相对真实季末滞后：最小0天、中位3天、最大6天。
- 2016Q1至2026Q1原有41季；删除成熟期内的2018Q1和2024Q1后只剩 **39季**，因此 `39 < 40 => BLOCK_SAMPLE`。

## 模型与防穿越

- 模型集合严格为：base、12个 single、old8、all12；没有变量筛选、交互、PCA、树、boosting、神经网络或阈值策略。
- 全部模型固定 Ridge `alpha=10`；标准化只使用当时训练折；脚本只有220行，低于300行软上限。
- 39个外层预测折全部独立重建训练集：`train end < test origin` 且 `train origin <= test origin - 92日`。
- 双 purge 违规：**0/39**；训练行数、最晚训练终点与最晚训练origin身份错误：**0/39**。
- 每折训练样本为25至63季。

## 独立闭式复算

- 不调用实验模型预测函数，使用标准化后的闭式 Ridge 解逐折重算。
- 预测：1,170格；最大绝对差 `1.388e-16`。
- 系数：4,836行；最大绝对差 `1.145e-16`。
- RMSE、MAE、Spearman rho最大差 `1.388e-17`。
- 12特征Spearman相关矩阵最大差 `0`。
- 固定输入连续运行两次的预测、系数和结果对象完全一致；实验自检的输出哈希复跑也报告一致。

## 39季诊断数字

- base：R63 RMSE `0.111307339`，MAE `0.086131960`，rho `+0.171255`。
- old8：RMSE `0.109599185`，相对base改善 `+1.534628%`。
- all12：RMSE `0.105118650`，MAE `0.083395668`，rho `+0.173887`；相对base改善 `+5.560001%`，相对old8改善 `+4.088110%`。
- 最好单条是 `single_vix_level`：RMSE `0.100629465`，相对base改善 `+9.593144%`。all12反而比它差 `4.461104%`，失败。
- 完整年份只有8年，all12改善4年、恶化4年，胜率 `50%`，低于60%门槛。
- 分段相对base均为正：2016–2020 `+5.638762%`；2021+ `+5.506041%`；排除2020/2022 `+4.599390%`。这些辅助诊断不能推翻样本门、最好单条门或年份门。
- W63反而恶化：all12 RMSE `0.071114186` 对 base `0.066724025`，即相对base `-6.579580%`；rho由 `+0.039919` 变成 `-0.027356`。

## 冻结门逐项判断

- all12相对base至少改善2%：PASS。
- all12比最好single至少再改善1%：**FAIL**。
- all12比old8至少再改善1%：PASS。
- 完整年份胜率至少60%：**FAIL**。
- 三个固定分段均改善：PASS。
- 合法成熟测试origin至少40：**FAIL，正式封锁原因**。

## 系数与组合含义

- all12的R63折中，VIX、Baa、breadth、A、B均为正39/39；real91为负39/39。
- EPS 13周变化为负39/39，D为负26/39，均与原本经济方向不稳定或相反；B为正39/39，继续呈现“收紧后反弹”而不是预设的负向领先关系。
- 这说明组合的诊断改善并不是12条各自贡献稳定、方向一致；最好单条仍是VIX水平。
