# QQQ 因素统一测试合同

## 固定目标

- 主目标：从信号日开始，QQQ 未来 63 个交易日终点回报。
- 辅助目标：同期从信号日起算的最差回报，用来识别下行风险。
- 主样本：每个自然季度最后一个可用观察点；所有宏观数据只向后匹配。

## 固定诊断

1. 连续变量 Spearman 排序相关。
2. 最低／最高三分之一的未来回报和下跌率。
3. 2009–2018 与 2019+ 两段方向稳定性。
4. 与过去 63 日 QQQ 回报的相关，检查是否只是价格动量换名。

## 判定

- `PASS standalone`：全样本绝对 rho 至少约 0.15，且两段时期方向一致。
- `REJECT standalone`：达不到以上条件；不改窗口、不找最优阈值。
- `PROXY interaction`：只有事先写明机制，才允许一个交互；不能用无限切格子救失败变量。
- `PASS incremental`：逐年 expanding + 92 日 purge，相对简单基线在至少 60% 年份改善，整体误差至少改善约 2%，且不是单一危机贡献。
- 策略检验只对 `PASS incremental` 开放，必须 T+1、含成本并与最简单基线比较。

历史区间已被查看，所以任何历史结果都不能称为完全 untouched OOS；最终必须从 2026-08-28 起保存真实预测快照。
