# G7／全球资金成本测试审计

更新时间：2026-08-29 01:28 MYT

## 人话结论

全球降息广度有历史预测信息，也明显改善风险调整表现，但固定策略仍因长期收益少得太多而未过最终标准。研究候选保留，生产使用拒绝。

```text
五个货币体系利率＋USDJPY
→ 月频利率至少滞后一个月、季度向后匹配
→ 三条候选统一诊断
   ├─ 全球降息广度：关系PASS
   ├─ 美国－海外利率差：REJECT
   └─ 日本加息×日元升值：方向相反，REJECT
→ 全球降息广度增量重放：PASS
→ 固定多数降息0x／1x策略：REJECT
→ 不接生产；进入上游Early Signal支线
```

## 经核对的结果

- 68个季度点，2009-06-26至2026-03-27；特征缺失0。
- 全球降息广度分布完整：0／1／2／3／4／5个降息体系分别有10／8／13／15／15／7季。
- 全球降息广度与未来63日QQQ回报Spearman rho `+0.237`；2009–2018 `+0.108`，2019+ `+0.352`。
- 相对“过去63日QQQ＋美国利率变化”基线，2017起扩展重放的回报RMSE改善`3.4%`，10年中6年改善。
- 严重跌幅Brier只改善`1.4%`，未过2%风险线；它不是暴跌预警。
- 固定策略：五个体系中至少三个过去91日利率下降时持有1x QQQ，否则现金；季度末信号、T+1开盘、25bps／200bps成本。
- 2017至今：策略25bps CAGR `17.5%`、Sharpe `1.19`、MDD `-22.9%`；QQQ CAGR `21.2%`、Sharpe `0.96`、MDD `-35.1%`。
- 最终失败点只有冻结的CAGR容忍线：策略落后QQQ `3.7pp`，标准最多容忍`2pp`。没有为救结果调整国家权重、窗口或多数阈值。

## 独立复核后的限制

- OECD／FRED月频3个月银行间利率是统一且免费的融资代理，不是央行OIS，也没有完整历史vintage。
- 本轮把月频值推迟到次月才可用，避免月末前偷看整月平均；但这不能证明当时发布版本与现在下载版本完全相同。
- 日本组合只有9个事件季度。冻结合同最低8个，因此可以计算，但独立审查建议正式判断至少15个；本轮方向已经与危险假设相反，所以仍是REJECT。
- 独立审查建议正式研究使用至少80个季度、HAC与多重检验，并在基线加入波动率；2009至今实际只有约68个成熟季度，因此当前结果只能称为约70分的历史候选，不是正式因果或独立OOS证明。
- 日本分支若未来单独重开，官方最佳描述性输入是日本财务省2年期JGB与BOJ USDJPY；两者同样没有完整历史vintage。不得用这条替代路线回头救本轮失败结果。

## 最终判定

| 层级 | 判定 |
|---|---|
| 数据可用性 | `PROXY PASS`：免费、历史足、可导出；无完整vintage |
| 单因素关系 | 全球降息广度 `PASS`；其余两条 `REJECT` |
| 历史增量重放 | 回报 `PASS`；风险 `REJECT` |
| 固定策略 | `REJECT` |
| 生产集成 | `STOP` |
| 研究价值 | `KEEP CANDIDATE`：可解释全球宽松环境，但不作为交易开关 |
